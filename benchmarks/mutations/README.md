# Mutation regression corpus (#93)

Controlled regressions generated by `tool_semantics.mutations`.

Each folder has:

- `before.json` — baseline snapshot
- `after.json` — mutated snapshot
- `expected-finding.json` — expected change codes / notes

Regenerate (optional):

```bash
python -c "from pathlib import Path; from tool_semantics.scanner import capture_manifest; from tool_semantics.mutations import MutationKind, MutationSpec, apply_mutation, write_mutation_case; snap=capture_manifest(Path('examples/github_server_v1.json'));
[write_mutation_case(Path('benchmarks/mutations')/k.value, apply_mutation(snap, MutationSpec(kind=k, seed=i)), case_id=k.value) for i,k in enumerate(MutationKind)]"
```

CI runs a fixed-seed subset via `tool-semantics mutate --seed 0`.
